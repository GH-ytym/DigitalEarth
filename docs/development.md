# 数字地球开发说明

工作台围绕图层管理和查询索引两个业务模块组织，基础地图操作集中在右侧控件。导航、面板、文字和图标统一采用深蓝与白色，通过蓝色背景变化表达选中状态。

## 代码阅读入口

1. `frontend/src/main.tsx` 在导入 Cesium 之前设置本地静态资源路径。
2. `frontend/src/App.tsx` 组织导航、业务面板、地图控件和资源状态。
3. `frontend/src/features/globe/GlobeViewport.tsx` 管理控制器创建与销毁。
4. `frontend/src/features/globe/SceneController.ts` 管理 Viewer、相机、图层、地形及拾取。
5. `frontend/src/features/locations/QueryPanel.tsx` 组织地名查询与坐标定位页签。
6. `frontend/src/config/scene.ts` 读取初始视角与浏览器端地形访问配置。

## 场景生命周期

React 状态只保存可序列化数据，控制器引用及 Cesium 对象不进入 React 状态。切换面板不重新挂载地球。

卸载时移除鼠标与相机监听，销毁 Viewer。底图与地形的异步任务均检查控制器是否已销毁；地形请求额外使用序号，避免过期请求在关闭或重试后重新替换 Provider。React StrictMode 的重复挂载也遵循这些清理规则。

场景采用按需渲染，图层、地形与选择变化后主动请求画面。相机动画由 Cesium 驱动；没有独立的昼夜动画或光照交互功能。

## 地形配置与状态

`frontend/.env.local` 保存浏览器端 Cesium ion 只读 Token，示例见 `.env.example`。真实配置不提交到仓库。Vite 在启动或构建时读取变量，因此修改配置后需重启或重新构建。

- 未配置：使用 `EllipsoidTerrainProvider`，不访问 ion 地形服务。
- 加载中：异步请求 Cesium World Terrain，保留可浏览的椭球面。
- 可用：替换为真实地形 Provider，切换到地形拾取。
- 已关闭：恢复椭球面，取消过期异步请求对场景的影响。
- 加载失败：恢复椭球面，保留明确错误提示和重试入口。

错误提示不直接展示服务端 URL 或 Token。地形故障与底图故障分别反馈；地形连接失败不会将整个场景标记为不可用。切换地形资源时清除旧的拾取结果，避免沿用不同表面的高度。

## 坐标与高度

经纬度为 WGS84 十进制度，高度是椭球高，不标记为海拔。

椭球面模式使用精确椭球交点，高度按定义为零。真实地形模式通过相机射线拾取已加载地形，精度受当前地形细节层次影响，不能视为测绘级结果。

坐标定位中的视角高度是相机的椭球高。真实地形模式下，标记贴地并异步采样地表高度；尚未获得高度或采样失败时保留未知值。采样结果检查地形请求序号和选中对象版本，避免更新到已清除或新选中的位置。

## 查询索引

目前坐标定位可用。地名查询页签明确显示服务尚未接入，不用固定城市列表模拟真实搜索。后续接入 Go 查询接口与独立 GeoNames 索引，再扩展业务参数索引。

## 验证要点

- 无 Token 时能够浏览本地地球，地形状态明确为未配置。
- 无效 Token 或网络失败时回退到椭球面，重试期间显示加载状态。
- 导航只有图层管理、查询索引，基础地图操作集中在右侧。
- 文字和图标使用纯白，选中与悬停状态使用蓝色背景。
- 查询页签切换、合法坐标定位、异常输入提示及地表拾取正常。
- 面板切换保留相机和选中位置，二维/三维切换无运行错误。
- 开发与生产构建均能加载本地 Cesium 静态资源。

有效 Token 下的真实地形加载、目标设备性能与真实地名查询，在具备访问配置和对应数据后另行验证。
