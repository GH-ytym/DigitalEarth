# 基础地球开发说明

当前阶段围绕一个可运行的地球工作区开展学习，优先理解 Viewer 生命周期、相机、影像、拾取和 React 界面联动。总体布局沿用项目展示文档。

## 从哪里开始阅读

1. `frontend/src/main.tsx` 在导入场景代码之前设置 `CESIUM_BASE_URL`，再启动 React。
2. `frontend/src/App.tsx` 组织顶部栏、导航、功能面板、地图控制和状态栏。
3. `frontend/src/features/globe/GlobeViewport.tsx` 在挂载时创建控制器，在卸载时销毁。
4. `frontend/src/features/globe/SceneController.ts` 创建 Viewer、加载影像、处理相机和鼠标事件，并输出普通数据快照。
5. `frontend/src/features/locations/CoordinatePanel.tsx` 校验经纬度和视角高度，再调用场景定位方法。
6. `frontend/vite.config.ts` 在开发和构建中提供 Cesium 的 Workers、ThirdParty、Assets、Widgets 四类资源。

## 场景与界面的关系

`App` 持有控制器引用，React 状态只保存普通数值和显示选项。Cesium 对象不进入 React 状态。面板的打开与收起只改变界面，`GlobeViewport` 始终保持挂载。

控制器持有 Viewer、图层、拾取事件和监听清理函数。卸载时先停止回调、移除监听和鼠标处理器，再销毁 Viewer。底图异步加载完成后检查控制器是否已销毁，避免 React StrictMode 或组件卸载期间向旧场景写入。

Cesium 使用按需渲染；底图、网格、光照和选择变化时请求新画面，相机动画仍由 Cesium 驱动。鼠标位置以约 60 毫秒为间隔更新界面，减少连续移动产生的 React 更新。

## 空间约定

- 坐标输入顺序为经度、纬度，采用 WGS84 十进制度。
- 经度范围为 −180 至 180，纬度范围为 −90 至 90。
- 当前不加载高程地形，拾取对象为椭球面，返回高度为椭球高，不能标记为海拔。
- 当前以 `camera.pickEllipsoid` 计算精确椭球交点，表面高度按定义为零，避免全球视角下对低精度渲染网格拾取产生虚假负高程。未来接入真实地形时改用对应的地形拾取方法。
- 定位输入中的高度是相机视角高度，单位为米；标记位于目标经纬度的椭球面，高度为零。
- 网格仅为浏览辅助图层，不用于量测或替代地理坐标轴。
- 昼夜光照使用当前场景时刻；本阶段没有业务仿真时钟，后续轨迹回放将统一设计。

## 资源与构建

首版不依赖在线地图或 Cesium ion。Natural Earth II 的本地数据只有 0 至 2 层，局部放大会模糊，属于当前数据的预期限制。

四个 Cesium 资源目录由 Vite 静态复制插件从锁定版本的 npm 包提供，生成于 `dist/cesium/`。前端使用相对基础路径，支持完整部署目录迁移；发布时应保留资源目录与相对引用。

Cesium 是较大的三维引擎，当前将其独立成一个生产分块。后续增加业务页面时可评估进一步按路由加载，不为消除体积提示而隐藏告警。

## 本阶段验收步骤

1. 开发模式打开页面，底图可见，状态显示场景就绪，浏览器无未处理错误。
2. 缩放、旋转、倾斜和复位；二维与三维切换后仍能操作。
3. 单击地表查看选中坐标；开关功能面板，确认视角和选中位置保留。
4. 切换纯色与自然地理底图，开关网格和光照，确认画面响应。
5. 输入合法经纬度定位；空输入、非数值、越界经纬度和越界视角高度均有明确提示。
6. 调整浏览器窗口，面板可滚动、控件可操作，场景尺寸随之更新。
7. `npm run build` 通过；使用 `npm run preview` 重复核心操作并检查静态资源。

## 下一阶段

建设 Go 地名查询接口和本地 GeoNames 索引。浏览器不直接连接数据库，不使用固定城市列表冒充真实地名查询。先对已有地名原件做字段与覆盖检查，再设计独立入库脚本及 `GET /api/v1/locations` 响应。

本阶段不启动数据库、不访问既有业务服务器，不导入轨迹或计算引力场与落点。

## 首版验证记录

2026 年 10 月 30 日，在 Windows、Node.js 22.17.1、npm 10.9.2 与 Microsoft Edge 环境下完成以下检查：

- 依赖安装成功，安装审计报告为零个已知漏洞。
- TypeScript 检查与生产构建通过，Cesium 四类静态资源及许可说明均生成。
- 开发服务与生产预览均显示本地地球，最终浏览器检查无控制台错误或警告。
- 自然地理与纯色底图切换、网格与昼夜光照开关生效。
- 二维与三维切换完成，切换期间禁用相机操作，避免读取过渡中的无效方向。
- 坐标定位完成后显示最终视角高度；空值、非数值、经度越界和高度越界均返回对应提示。
- 单击地表取得精确 WGS84 椭球坐标，高度为零；切换面板后选中位置与视角保持，页面仍只有一个 Viewer 和画布。
- 1000 × 700 视口下无横向页面溢出，面板可滚动，地图与控件保持可用。

生产构建保留 Cesium 引擎分块体积提示，未将其视为构建失败。真实地形、真实地名服务、目标设备性能和完整离线交付尚待对应阶段验证。
